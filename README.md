# Catch Cold Mod  
- Adds 2 brand new affliction  
- Adds a new buff
## How it works
### Cold Risk
If your are below the third of your temperature meter (below 33%), then you build up Cold Risk. The duration of this can be modified in the settings menu.  
The risk can be depleted if the player is FULLY warmed up.  
If the risk timer reaches 100%, then you have a roll to catch a Cold Affliction. There are quite a few factors which affect this roll's chance.  
- There is the base chance, which can also be configured within the settings.
